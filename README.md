# CASINR: Double or Nothing

*Because gambling with your financial future wasn't quite exciting enough without blockchain technology.*

## What's All This Then?

CASINR is a thoroughly modern take on the age-old tradition of parting with one's money in the hope of receiving slightly more in return. Built with React, TypeScript, and Vite, this application allows users to experience the thrill of the "Double or Nothing" game using Solana cryptocurrency.

Think of it as the digital equivalent of that mate who always says "I'll pay you back next week" - except in this case, the blockchain ensures transparency (if not necessarily profit).

## Features

- **Phantom Wallet Integration**: Connect your Phantom wallet with fewer steps than it takes to make a proper cup of tea.
- **Solana Transactions**: Send SOL with the same ease as accidentally liking someone's Instagram post from 2016.
- **Double or Nothing Gameplay**: A sophisticated algorithm (read: glorified coin toss) determines whether you double your SOL or lose it all.
- **Responsive Design**: Looks smashing on both your desktop and mobile, so you can make questionable financial decisions from anywhere.

## Getting Started

### Prerequisites

- A modern web browser (if you're still using Internet Explorer, we have bigger concerns than cryptocurrency gambling)
- [Phantom Wallet](https://phantom.app/) browser extension
- Some SOL in your wallet (acquired through means we're legally obligated not to advise on)
- A healthy relationship with risk

### Installation

```bash
# Clone the repository (or download it, we're not fussy)
git clone https://github.com/yourusername/casinr_website_react.git

# Navigate to the project directory
cd casinr_website_react

# Install dependencies (and watch your disk space vanish like your crypto during a bear market)
npm install

# Start the development server
npm run dev
```

## Usage

1. Connect your Phantom wallet by clicking the "Connect to Phantom Wallet" button.
2. Enter the amount of SOL you wish to wager (we recommend an amount you're comfortable discussing with your significant other).
3. Click "Send Transaction" and wait for the blockchain gods to determine your fate.
4. Celebrate wildly or quietly contemplate your life choices, depending on the outcome.

## Technical Details

This project is built with:

- **React 18**: Because we like our DOM virtual and our components functional.
- **TypeScript**: For when JavaScript's "any" type just isn't keeping you up at night enough.
- **Vite**: Because life's too short to wait for webpack to bundle.
- **Solana Web3.js**: For interacting with the Solana blockchain in a way that only occasionally makes you question your career choices.
